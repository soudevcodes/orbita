# Glossário

Banco tem muita palavra estranha. Aqui está o que elas querem dizer, em português de gente.

| Termo | O que é |
|---|---|
| **Fatura** | A conta do cartão de crédito do mês: tudo o que o cliente comprou entre um fechamento e outro. |
| **Fechamento** | O dia em que a fatura "fecha": compras a partir dele vão para a fatura seguinte. |
| **Vencimento** | O último dia para pagar a fatura sem multa. |
| **Melhor dia de compra** | O dia do fechamento: comprando nele, o cliente tem o máximo de tempo até pagar. |
| **Pagamento mínimo** | O menor valor que o cliente pode pagar para não ficar em atraso. O resto vira rotativo. |
| **Rotativo** | A parte da fatura que o cliente não pagou e que passa para o mês seguinte com juros. É o crédito mais caro do país — por isso o teto legal. |
| **Juros de mora** | Juros cobrados porque o pagamento atrasou. |
| **Multa** | Valor fixo (percentual) cobrado uma vez pelo atraso. |
| **Inadimplência** | Cliente que não pagou. Aqui, contamos quem está com mais de 30 dias de atraso. |
| **Limite** | O máximo que o cliente pode gastar no cartão de crédito. |
| **Elegibilidade** | Se o cliente pode ou não receber o cartão. |
| **Estorno** | Devolução de uma compra. Vira crédito na fatura. |
| **Parcelamento sem juros** | Dividir uma compra em parcelas iguais nas próximas faturas, sem custo extra. |
| **Idempotência** | Fazer a mesma operação duas vezes dar o mesmo resultado de fazer uma vez só. É o que impede o Pix em dobro. |
| **Chargeback** | Quando o cliente contesta uma compra que não reconhece. |
| **Dia útil** | Segunda a sexta, menos feriados nacionais. |
| **5º dia útil** | Prazo legal para empresas pagarem salário. É o dia de maior movimento do app. |
| **LGPD** | Lei Geral de Proteção de Dados. Define como dado pessoal pode ser usado e guardado. |
| **Banco Central (BC)** | Quem regula os bancos no Brasil e o Pix. |
| **SEV1 / SEV2 / SEV3** | Gravidade de um incidente (ver [como trabalhamos](05-como-trabalhamos.md)). |
| **Postmortem** | Documento escrito depois de um incidente: o que aconteceu, por quê, e o que muda. Sem culpados. |
| **PR (pull request)** | O pedido para colocar sua mudança no código principal, revisado por outra pessoa. |
| **Daily** | A atualização diária do time. Aqui ela é escrita. |
